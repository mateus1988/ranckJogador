# ⚽ Sistema de Ranking de Jogadores

## 📌 Descrição
Este projeto foi desenvolvido com o objetivo de ranquear jogadores( amigos da resenha) com base em seu desempenho em campo ou quadra .

O sistema utiliza os seguintes dados:
- ⚽ Gols
- 🎯 Assistências
- 🕹️ Partidas jogadas
- Jogos Jogados

Além disso, o projeto conta com integração de API para exibir data e hora em tempo real e uma tabela com gráfico comparativo entre jogadores.

---

## 🎯 Objetivo
Praticar conceitos fundamentais de programação como:
- Entrada e saída de dados
- Estruturas condicionais
- Lógica de programação
- Cálculo de desempenho
- Organização de dados

---

## ⚙️ Tecnologias Utilizadas
- ☕ Html,Css e JavaScript
- 📊 Estruturas de dados (Listas/Arrays)
- 🌐 API de data e hora
- 📈 Geração de gráficos

---

## 🧠 Como funciona o ranking

O sistema calcula o desempenho dos jogadores com base nas estatísticas informadas.

### Exemplo de entrada:
Nome: Mateus  
Gols: 10  
Assistências: 5  
Partidas: 8  

### Exemplo de saída:
1º Lugar - João  
2º Lugar - Mateus  
3º Lugar - Carlos  

---

## 📈 Funcionalidades
- Cadastro de jogadores
- Cálculo automático de desempenho
- Ranking de jogadores
- Exibição de data e hora via API
- Comparação de jogadores com gráfico
